# Word Quest: B2 English Challenge

A browser-based single-page English-learning game for approximately CEFR B2 learners, built with plain HTML, CSS, and JavaScript.

## Run locally

```bash
npm install
npm start
```

Then open the local URL shown by `servor`.

## Game features

- 15-question rounds pulled from a larger B2-focused question bank
- Three question types:
  - Contextual vocabulary choice
  - Phrasal verb / collocation challenge
  - Sentence transformation and grammar choice
- Score tracking with streak-based combo multiplier
- Progress indicator, immediate feedback, and explanation after each submission
- End-of-round results summary plus restart for another round
- Responsive, keyboard-friendly, semantic UI with visible focus states and accessible feedback

## Level targeting

The prompts and explanations are designed for roughly CEFR B2 (upper-intermediate) practice, focusing on nuanced meaning in context rather than beginner matching.
